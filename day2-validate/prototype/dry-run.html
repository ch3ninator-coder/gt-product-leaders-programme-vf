This page runs 200 made-up returned applications through the same checklist rules the parent sees and counts how many it would have flagged.

What this can and can't tell us

We wrote these 200 cases ourselves, with the reason mix we assumed. So the dry run proves the checklist rules work as designed, and shows how close the idea is to the stop line. It can't prove that real child returns are 56% document problems.

The real test is ICA's own count of child returns by reason, as totals with no personal data. If that count puts missing or wrong documents below about 45% of returns, the checklist can't reach the 50% continue line even before false ticks, and the idea should pivot.
