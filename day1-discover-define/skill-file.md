# Skill File — Scenario B: ICA Passport Application Review Assistant

## Focus Area

AI assistant to help **ICA officers** quickly identify errors and missing documents in passport applications, reducing manual review time and generating clear return notices.

---

## Problem

Officers return **17% of submissions** for errors or missing documents. Each return adds approximately **6 days** to the application process. Officers spend significant time:

1. Manually checking each application for completeness
2. Cross-referencing applicant situation (adult/child, new/renewal) against requirements
3. Writing return notices that explain what's missing or incorrect

---

## User

**ICA Processing Officers** who review passport applications daily.

### Current Pain Points

- High volume of incomplete applications to review
- Repetitive manual checks across different application types
- Writing clear, specific return notices takes time
- Parent-child renewals are the most complex to verify

---

## AI Skill

An AI assistant that **reviews submitted applications** and:

1. **Flags errors and missing documents** based on applicant type (adult/child, new/renewal)
2. **Highlights what's wrong** with specific fields or attachments
3. **Drafts return notices** with clear instructions for the applicant

---

## Constraints

- Applications contain **identity documents and sensitive personal data** — AI must not store or log document contents
- Officer makes final decision — AI recommends, human approves
- Must integrate with existing ICA processing workflow
